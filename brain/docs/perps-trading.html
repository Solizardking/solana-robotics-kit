CLI Reference

      
Phoenix perps + Vulcan from the terminal.

      

        The same strategy plans generated in the dashboard can be created directly
        from the Meta Mesh CLI, with full Vulcan execution mode support and
        approval-gated safety boundaries.
      


      

        
Market Data & Ticker

        # Fetch current Phoenix perps ticker
        python -m solana_robot_harness.cli phoenix-market --kind ticker --symbol SOL
        # Read orderbook depth
        python -m solana_robot_harness.cli phoenix-market --kind orderbook --symbol SOL
      


      

        
TWAP Strategy Plan

        # Paper mode — no wallet or chain activity
        python -m solana_robot_harness.cli phoenix-perps-plan \
  --strategy twap --symbol SOL --side buy \
  --notional-usdc 50 --slices 5 \
  --interval-seconds 60 --mode paper
      


      

        
Grid Strategy Plan

        # Dry-run mode — build transactions but do not send
        python -m solana_robot_harness.cli phoenix-perps-plan \
  --strategy grid --symbol SOL \
  --center-on-mark --width-pct 1.5 \
  --levels-per-side 3 --tokens-per-level 0.1 \
  --mode dry-run

Safety Contract

      

        The Perps Trading Demo follows the same safety contract as Meta Mesh for the Brain:
        every strategy plan is a proposal, not an execution. The harness never holds keys,
        never signs transactions, and never submits trades without explicit operator approval
        at the appropriate mode level.
      


      

        
Execution Mode Safety

        

          

            Observe
            Read-only market data. No orders, no paper trades, no transactions.
          

          

            Paper
            Simulated orders against live prices. No wallet or chain activity.
          

          

            Dry Run
            Full transaction construction but never sent. Review before submission.
          

          

            Confirm
            Every individual order requires explicit operator approval.
          

          

            Auto
            Autonomous execution with USDC notional guardrails and risk checks.
